# Vacuum Orchestrator Card

Vacuum Orchestrator Card is a planned custom dashboard card for Home Assistant.
It will provide a visual interface for the separate Vacuum Orchestrator custom
integration, including its cleaning-job queue, job editor, execution status,
readiness blockers, and queue controls.

The card is intended to remain optional. Vacuum Orchestrator's backend features
will also be available through standard Home Assistant actions and automations.

## Project status

This repository is an initial project scaffold. It does not contain an
installable card or a release yet. Installation and configuration instructions
will be added when a tested preview is available.
